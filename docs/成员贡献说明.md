| 模块 | 职责 | 具体贡献 |
|------|------|----------|
| M1 工程脚手架 | 项目初始化与质量门禁 | 分层目录与 pyproject 配置（ruff/mypy strict/pytest-cov）；Dockerfile 与 docker-compose（dev）；GitHub Actions CI 三阶段；.gitattributes 行尾治理；健康检查 /healthz |
| M2 领域层与数据层 | 核心业务规则与数据访问 | Base62 安全随机短码（secrets）；有效期四档策略（1h/24h/7d/forever，naive UTC 约定）；访问次数策略；Share ORM 模型与 Alembic 迁移；Repository 模式；守卫式原子自增 `increment_view_count_guarded`（并发不超卖） |
| M3 REST API 层 | 接口契约与横切安全 | 创建/读取/raw/二维码四个端点（Problem Details 统一错误模型）；速率限制（slowapi）与 429 处理器；安全响应头中间件（CSP 等）；structlog 结构化日志；`--no-access-log` 隐私加固（审查发现后修复） |
| M4 Web 前端 | 页面与安全渲染 | 创建页/查看页（页面 shell 架构，访问计数只经 API 一次）；内容类型自动识别（JSON/Markdown/代码/纯文本打分制）+ 手动切换；XSS 三层防御（textContent / DOMPurify / CSP）；响应式布局；jsdom 前端冒烟脚本 |
| M5 创新点 A：E2E 加密 | 端到端加密分享 | crypto.js（WebCrypto AES-256-GCM，密钥仅存链接 fragment）；`ENC1:` 密文标记格式（版本前缀 + base64url IV/密文）；服务器零明文（数据库层 + API 层双层断言）；加密后长度本地校验（1.4 倍膨胀） |
| M5 创新点 B：CLI 工具 | 命令行分享工具 | `clipshare send` / `clipshare get`（含 @file、--expiry、--max-views、--base-url、CLIPSHARE_BASE_URL 环境变量）；退出码契约 0/1/2；可注入 httpx 客户端设计（MockTransport 单测 + TestClient 进程内冒烟）；stdout/stderr 分流 |
| M6 生产部署 | 部署基础设施 | docker-compose.prod.yml（`${VAR:?}` 强制校验）；conf/nginx.conf（反代、XFF 覆盖防限流绕过、access_log off）；scripts/deploy.sh 一键部署（迁移+健康检查）；scripts/backup.sh 备份脚本（保留 N 份）；生产镜像补 COPY alembic 迁移文件（无热挂载兜底）；docs/DEPLOYMENT.md 部署手册 |
| M7 文档交付 | 最终文档与演示材料 | README 定稿；docs/API.md（书面 API 文档）；docs/开发心得.md（真实踩坑与解决方案汇总）；docs/演示视频脚本.md；docs/成员贡献说明.md；前端冒烟（jsdom）接入 CI（package.json + e2e job）；CLAUDE.md 阶段更新 |
